## EchoAgent

主导 EchoAgent Runtime 与企业 Agent 的架构设计和工程建设，面向开发者与企业团队提供智能体运行与协作工具。

### EchoAgent Runtime

面向开发者的智能体运行时，可自托管、可嵌入应用，支持任务执行、长期记忆、工具调用与 Skills 扩展，适用于需要持续运行和复用任务经验的 Agent 应用。

### EchoAgent 企业 Agent

面向企业员工与业务团队的桌面智能体协作平台，在同一工作台中连接模型、组织知识、业务数据与工具。

- **任务协作**：由业务、数据与写作等专家分工，完成知识检索、数据分析和文档交付。
- **业务连接**：通过文档检索、业务语义和受控查询使用组织资料与业务数据，并保留结果依据。
- **运行治理**：结合私有化部署、组织权限与模型调用策略，管理执行审批、审计和使用额度。
